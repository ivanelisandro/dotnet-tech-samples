# Components Techniques

This is a simple project to experiment with some Blazor techniques.

## Objectives

- Understand how a `RenderFragment` can be used to make a component serve as a container for very different children components;
- Understand how `@inject` can be used to consume a service in a component;
- Understand how `CascadingValue` can be used to share a value in a hierarchy without explicitly passing it;
- Understand how `@ref` can be used for component reference;
